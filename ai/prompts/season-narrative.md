# 시즌 결과지 서술 프롬프트 — ④ 실제 모습 · ⑦ 예상과 실제의 차이

`data/blocks/*.json` 의 블록은 **미리 만들어 두고 고르는** 문장이다. 이 파일은 다르다 —
런타임에 GMS 게이트웨이로 보내는 프롬프트이고, `app/services/season_narrative.py` 가 읽어 쓴다.

**아래 코드 블록 두 개가 그대로 요청에 실린다.** 순서가 곧 역할이다.

1. 첫 번째 블록 = `developer` 메시지 (지침)
2. 두 번째 블록 = `user` 메시지 틀. `{이름}` 자리는 `season_narrative.py` 가 채운다

## 왜 이 자리에만 LLM 을 쓰는가

```
유형 8 × 부제 2 × 일치도 구간 3 × 갈린 축 4 × 방향 2 = 384 조합
변주 2개씩이면 블록 768개 — 지금 전체 재고의 여섯 배
```

헤드라인은 조건이 12개라 블록으로도 됐지만 여기는 조합이 폭발한다. **점수·유형·일치도에는
LLM 이 관여하지 않는다** — 같은 입력에 다른 점수가 나오면 리포트가 폐장 스냅샷이 아니게 되고,
옆 칸의 승률과 모순되는 순간 전부 무너진다.

## 무엇을 넘기고 무엇을 안 넘기나

| | |
|---|---|
| 넘긴다 | 방향 문장 둘 · 선언 유무 |
| **안 넘긴다** | 축 점수(숫자) · 계좌 번호 · 종목명 · 체결 원본 · 수익률 · 순위 · 일치도 |

**점수 대신 방향 문장을 넘긴다.** 헤드라인에서 한 번 겪었다 — `mainMistake` 를 "가장
두드러졌다"로만 적었더니 모델이 잘한 일로 읽고 "성과를 이끌었습니다"를 냈다(실측). `TIME = 82`
를 주면 82를 "길다"로 읽을 여지가 있어서, 방향을 문장으로 확정해 넘기고 모델은 잇기만 한다.

종목명·계정을 넘기지 않으므로 **익명화가 지침이 아니라 구조로 지켜진다.**

## 받는 모양

```json
{ "actual": "두 문장" }
```

검사에 걸리거나 파싱이 깨지면 `actual_fallback` 블록으로 내려앉는다.

### ⑦ 은 왜 여기 없나

처음에는 `gap` 도 함께 받았는데 **실호출에서 모델이 세 번 다 틀렸다.**

```
축을 섞었다        ENTRY 선언인데 "오래 들고 갈 생각이라 하셨지만" (TIME 문구)
틀을 섞었다        MATCHED 틀에 OPPOSITE 내용
반쪽만 썼다        "실제로는 …" 만 있고 선언 쪽이 없다
```

⑦ 은 조합이 **축 4 × 방향 2 × 판정 2 + 일치 1 = 열일곱**뿐이라 블록이 정확히 덮는다.
④ 는 두드러진 축 둘을 자연스럽게 잇는 일이라 조합이 폭발하고, 실호출에서 깨끗하게 나왔다 —
**LLM 이 값을 하는 자리와 못 하는 자리가 여기서 갈렸다.**

## 지침 (developer 메시지)

```text
당신은 모의투자 게임의 시즌 복기 리포트를 쓰는 카피라이터다.
사용자가 지금까지 한 매매를 판정한 결과가 주어진다. 그것을 사람이 읽는 문장으로 옮긴다.

[출력 형식 - 어기면 전부 버려진다]
JSON 객체 하나만 출력한다. 마크다운·머리말·설명을 붙이지 않는다.
  {"actual": "..."}

[actual - 실제 투자에서 나타난 모습]
1. 정확히 두 문장. 각 문장 45자 안팎이고 합쳐서 110자를 넘기지 않는다.
2. 주어진 '두드러진 점' 두 줄을 자연스럽게 이어 쓴다. 없는 사실을 보태지 않는다.
   '선언' 항목은 참고용이다. 문장에 옮기지 않는다.
3. '지금까지의 거래를 보면' 처럼 기간을 짚어 여는 것이 좋다.
4. 두 문장이 같은 말로 시작하지 않는다.

[모든 문장에 공통]
1. 반드시 '습니다.' 로 끝낸다. ('~된다', '~이다', '~했다' 같은 종결은 쓰지 않는다)
2. 기간을 날수로 적지 않는다. 리포트가 매일 나오고 그때까지의 거래를 누적해서 보므로
   '3일'·'사흘' 은 첫날과 둘째 날에 거짓이 된다. '지금까지'·'여기까지' 로 쓴다.
   숫자는 한 글자도 쓰지 않는다 — 아라비아 숫자도, '나흘'·'이틀' 같은 한글 수사도.
   수치는 결과지의 다른 칸이 이미 보여준다.
3. 실제 고유명사(종목명·지수명·사건명)를 쓰지 않는다.
4. 투자를 권유하지 않고 훈계하지 않는다.
5. 지금까지의 거래를 사람의 전부로 단정하지 않는다. '여기까지만 놓고 보면' 쪽으로 쓴다.
6. 손실을 본 사람에게 잔인하지 않되 억지로 위로하지도 않는다. 관찰하고 판단하지 않는다.

[선언이 '없음' 일 때 - 특히 조심할 것]
'생각과', '예상과', '달리', '반대로', '의외로' 를 쓰지 않는다.
선언한 적이 없는 사람에게 그렇게 쓰면 없는 선언을 지어낸 문장이 된다.

[서비스]
2020~2026년 실제 시장을 3일 만에 재생하는 멀티유저 모의투자 게임이다.
플레이어는 하루가 끝날 때마다 그때까지의 매매로 판정한 투자자 유형 결과지를 받는다.
```
