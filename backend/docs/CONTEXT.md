# 백엔드 도메인 용어

이 컨텍스트가 다루는 고유 용어를 정의한다. 코드·문서·API·커밋에서 같은 개념은 여기 정한 단어로만 부른다.

## 언어 (Language)

**User**:
서비스에 등록된 사람 하나. `users` 테이블의 한 행이며, 도메인 전반은 `users.id`로 사람을 가리킨다.
User 존재 여부와 현재 세션(로그인) 보유 여부는 완전히 독립된 개념이다.
_Avoid_: Member, 회원 (같은 개념을 두 단어로 부르게 된다), Account (계좌와 충돌한다),
방문자 (등록되지 않은 주체이므로 User 가 아니다)

**Unauthenticated (미인증)**:
요청에 유효한 세션이 없는 상태. 가입이나 등록 이력과 무관하다 — DB 에 존재하는 User 라도
로그아웃했거나 세션이 만료되면 미인증이다. API 접근 제어와 공개 화면 판정은 오직 이 상태 하나로만 결정한다.
_Avoid_: 비로그인 (화면용 일상어), 익명·게스트 (익명 계정/임시 유저 도메인 모델이 있는 것으로 오해된다),
미등록 방문자 (가입 여부와 결합되어 권한 판단을 흐린다)

**OAuth Account**:
한 User가 특정 Provider에서 갖는 신원. `oauth_accounts` 테이블의 한 행이고
`(provider, provider_user_id)` 조합이 유일하다. 한 User는 여러 OAuth Account를 가질 수 있다.
_Avoid_: 소셜 계정, 연동 계정, 외부 계정

**Provider**:
인증을 수행한 외부 IdP를 식별하는 문자열. 현재 값은 `google`, `ssafy` 두 개다.
화면 문구는 **"로그인 방법"** 으로 통일한다 ("로그인 수단", "연결된 계정", "소셜 로그인"을 쓰지 않는다 —
`계좌`가 등장할 화면에서 "계정"이 혼동되고, "소셜 로그인"은 이 항목의 회피어다).
Test User 는 Provider 를 갖지 않는다.
_Avoid_: 벤더, 플랫폼, 소셜, IdP (코드에 쓰는 이름은 `provider`로 통일한다)

**Provider User ID**:
Provider가 발급한 그 사용자의 불변 고유 식별자. Google에서는 ID 토큰의 `sub` 클레임이고,
SSAFY에서는 user-info 응답의 `userId` 다 (SSAFY는 OIDC가 아니라 ID 토큰이 없다).
사용자가 이메일이나 이름을 바꿔도 변하지 않으므로, 동일인 판정은 이 값으로만 한다.
_Avoid_: 소셜 ID, 외부 ID, 이메일 (이메일은 표시용 속성이지 식별자가 아니다)

**Test User**:
테스트와 부하측정 전용으로 만들어진 User. OAuth Account 를 갖지 않아 로그인 방법이 하나도 없고,
관리자 콘솔의 사용자 목록에도 나타나지 않는다 — 사용자가 아니라 테스트 장치다.
_Avoid_: 테스트 계정 (`Account` 는 계좌와 충돌한다), 더미 User, 목 User, 가상 유저

**Sandbox**:
관리자가 자신에게 배정된 Test User 의 세션으로 갈아타 USER 시점에서 서비스를 보는 상태.
대상은 배정된 Test User 하나로 고정이며 다른 사람으로는 전환할 수 없다.
_Avoid_: Impersonation, 사용자 가장, 계정 전환, 대리 로그인, 뷰 모드

**Inquiry (문의)**:
사용자가 관리자에게 보내는 질문 하나와 그에 대한 답변 하나. 스레드가 아니므로 재질문은 새 Inquiry 다.
_Avoid_: QA, Q&A, 문의사항, 티켓, 1:1 상담, 고객센터

**Audit Log (감사 로그)**:
관리자 권한으로 수행된 행위의 불변 기록. 추가만 가능하고 대상이 사라져도 남는다.
_Avoid_: 이력, 히스토리, 활동 로그 (애플리케이션 로그와 혼동된다)

## 마켓 리플레이 (Market Replay)

**Season (시즌)**:
게임이 한 번 열리고 닫히는 단위. 세 개의 Season Day 로 이루어지며, 한 User 는 한 시즌에서 Account 를 하나 갖는다.
_Avoid_: 회차, 라운드, 대회 (기간이 아니라 경쟁 이벤트로 읽힌다), 게임 (재생 전체를 가리키게 된다)

**Season Day (일차)**:
시즌을 이루는 하루. 1·2·3 의 값을 가지며 네 개의 Phase 를 차례로 지난다. 일간 순위·정산·복기의 단위다.
_Avoid_: Day, 날짜, 게임 날짜 (Tick 이 공개하는 가상 거래일 `gameDate` 와 혼동된다 — 하루의 일차와 그날 공개되는 가상 날짜는 다르다, 시대 (관리자 시간 이동에서 쓰인 말이지만 이동 단위가 일차·월·Tick 셋이라 어느 것인지 가리지 못한다)

**Tick**:
확정된 종가 하나와 그 공개 위치. 재생 일정의 가격 공개 단위이고 시즌 시작부터 이어지는
순번(`tickSeq`)으로 식별한다.
화면 문구는 **"일봉"·"종가"** 로 통일한다 (코드·API는 `Tick`).
_Avoid_: Candle, 캔들, 봉 (고가·저가·시가를 쓰지 않는 단일 가격 모델과 정면으로 충돌한다), 스텝, 프레임

**Phase**:
하루를 나누는 네 구간 중 하나 — `BRIEFING`·`TRADING`·`SETTLING`·`REVIEW_ONLY`. 게임 가상 시간의 업무 경계로 결정되며
거래·채팅·리더보드의 가용 여부가 여기서 갈린다. `game.phase` 메시지와 `GET /api/v1/game/clock`이 나르는 값이다.
**`feeFree`(수수료 무료 구간)와 `leaderboardBlackout`(암전)은 별도 Phase가 아니라 `TRADING` 안의 플래그다** —
둘 다 거래가 계속되므로 Phase로 쪼개면 "거래 가능한 Phase가 3개"가 되어 모든 게이팅 표기가 복잡해진다.
_Avoid_: 상태, 단계, 세션, 장(場) (같은 개념을 여러 단어로 부르게 된다), 일시정지 (재생 시계의 정지와 구간은 별개다)

**Replay Schedule (재생 일정)**:
각 Tick이 시즌의 어느 일차·가상 위치에서 공개되는지 정한 불변 일정. 배속 변경이나 되감기로 바뀌지 않는다.
_Avoid_: 실제 공개 시각, 운영 일정

**Replay Clock (재생 시계)**:
실제 시간과 게임 가상 위치의 대응 관계. 정지·배속·되감기는 이 시계에 적용하며 실제 발생 시각과 운영 일정은 바꾸지 않는다.
_Avoid_: 서버 절대 시간, DB 절대 시간 (실제 시간과 게임 가상 시간을 혼동한다)

**Operating Schedule (운영 일정)**:
프로덕션에서 날짜별 개장과 다음 브리핑의 실제 시각을 정하는 일정. 재생 배속과 되감기의 영향을 받지 않는다.
_Avoid_: 재생 일정

**Published Tick (공개 기준 틱)**:
가격과 관련 게임 정보의 공개 기준이 되는 Tick. **직전 값 +1 로만 전진한다** — 건너뛰는 설정은 없다.
Warp 에서도 같은 규칙으로 하나씩 전진하고, 시즌 초기화에서만 미공개 상태로 되돌아간다.
_Avoid_: 목표 틱, 현재 시각의 틱 (처리 완료를 뜻하지 않는다)

**Seek (지점 이동)**:
관리자가 재생 위치를 원하는 Replay Mark 로 옮기는 조작. 목표가 현재보다 앞이면 Warp 하나로 끝나고,
뒤면 시즌 데이터를 초기화한 뒤 목표까지 Warp 한다 — **뒤로 가는 재생은 없다**.
_Avoid_: 되감기 (Tick 을 역순으로 재생하는 것으로 읽힌다), 텔레포트, 앵커 이동, 점프

**Warp (빨리감기)**:
목표 지점까지의 Tick 과 시간 경계를 **순서대로 모두 처리하며** 그 지점에 도달하는 조작.
벽시계를 기다리지 않을 뿐이고 체결·IPO 배정·정산·발행은 전부 실제로 일어난다. 앞으로만 간다.
_Avoid_: 스킵·건너뛰기 (사이 구간이 일어나지 않는다고 읽히지만 그런 조작은 이 도메인에 없다), 배속 (배속은 시계의 속성이고 Warp 는 조작이다)

**Replay Mark (이동 지점)**:
Seek 의 목표로 지정할 수 있는 재생 일정 위의 한 지점. 일차 경계·월의 첫 Tick·IPO 공시·마감·상장 등이며
서버가 시즌 편성에서 계산해 목록으로 제공한다. 화면 문구는 **"이동 지점"** 으로 통일한다.
_Avoid_: Event (`TickPublishedEvent`·`PhaseBoundaryEvent` 등 실행 중 발행되는 인메모리 이벤트와 충돌한다), 북마크, 체크포인트, 마일스톤

**Replay Epoch (재생 실행 세대)**:
시즌 초기화 전후의 재생 실행을 구분하는 세대. 초기화마다 1 오르며 모든 실시간 봉투에 실린다 —
끊겼던 클라이언트가 재접속 직후 첫 메시지에서 불일치를 알아차리는 자리다.
배속 변경·정지·재개·앞으로 가는 Seek 은 같은 세대에 속한다.
_Avoid_: 시즌 번호, 틱 번호

**Instrument (종목)**:
유니버스에 편성된 거래 대상 하나. 주식·ETF·코인을 함께 가리킨다.
_Avoid_: Symbol (티커 문자열은 식별자이지 종목 자체가 아니다), Asset (보유 자산과 충돌한다), 상품, 티커

**Universe (유니버스)**:
한 시즌에서 거래할 수 있는 Instrument 의 집합. IPO 상장으로 늘어나며 줄지 않는다.
_Avoid_: 종목 풀, 상장 목록, 마켓

**Watchlist (관심종목)**:
한 User 가 따로 모아 보는 Instrument 의 집합. 계좌가 아니라 User 에 붙으므로 시즌과 무관하다.
상장 예정 종목도 담을 수 있다. 화면 문구는 **"관심종목"** 으로 통일한다 (코드·API는 `Watchlist`).
_Avoid_: 즐겨찾기, 북마크, 찜, 관심목록

**Participation (참가)**:
한 User 가 한 시즌의 경쟁에 들어가 있는 상태. **Account 의 존재가 곧 참가이며 별도의 참가 행위가 없다** —
시즌 중 로그인이 참가를 만든다.
_Avoid_: 가입·등록 (User 등록과 혼동된다), 입장, 엔트리, 참여 (같은 개념을 두 단어로 부르게 된다)

**Account (계좌)**:
한 User 가 한 시즌에서 갖는 자산 전체 — 원화 현금(`krwCash`)·달러 현금(`usdCash`)·보유 종목과 수량.
1인 1계좌이며 **로그인 계정의 뜻으로 쓰지 않는다** (그쪽은 User · OAuth Account).
_Avoid_: 지갑 (통화별 현금은 계좌의 필드이지 별도 리소스가 아니다), 포트폴리오, 잔고

**locked (잠긴 금액·수량)**:
예약 주문이나 청약이 점유해 다른 주문·환전에 쓸 수 없는 몫. 매수는 현금이, 매도는 보유 수량이 잠긴다.
_Avoid_: hold, 동결, 예치, 묶인 돈

**Order Type**:
`MARKET` 은 즉시 전량 체결되어 미체결 상태를 거치지 않고, `LIMIT` 은 이후 Tick 에서 조건이 맞으면 체결된다.
화면 문구는 **"시장가"·"예약"** 으로 통일한다.
_Avoid_: Reservation (좌석·숙소 예약 어감이라 "가격 조건이 맞으면 체결된다"가 전달되지 않는다), 화면에 "지정가" 그대로 쓰기

**Open Order (미체결 예약)**:
아직 체결되지 않은 `LIMIT` 주문. 수정·취소할 수 있고 그날 폐장에 소멸한다.
_Avoid_: Pending Order, 대기 주문 (체결의 반대말이 아니라 "살아 있는 예약"이다)

**Execution (체결)**:
성사된 거래 하나의 불변 기록. 적용 수수료율과 실현손익을 그 시점 값으로 담으며 복기와 시즌 리포트의 원천이다.
_Avoid_: Trade, Fill, 거래 내역, 매매 기록

**Exchange (환전)**:
원화와 달러를 맞바꾸는 행위. 보내는 통화 기준 금액으로 요청한다.
_Avoid_: Conversion, 환거래, 교환 (Instrument 매매와 혼동된다)

**Subscription (청약)**:
IPO 공모주에 참여하는 행위. 종목당 1인 1청약이다.
_Avoid_: Application, 공모 신청, 구독 (이 컨텍스트에 정기 결제 개념이 없어 혼동만 남는다)

**Seed (시드)**:
시즌 참가자에게 지급하는 시작 자금의 기준 금액. 시즌이 소유하는 값이며 Account 의 시작 잔고는 여기서 산정한다.
_Avoid_: 초기 자본, 종잣돈, 시드머니 (표기가 갈린다), 예치금,
시작 잔고 (그쪽은 계좌에 실제로 지급된 금액이라 시드와 다를 수 있다)

**Index-adjusted Starting Balance (소급 인덱스 잔고)**:
1일차 개장 이후 합류한 User 의 시작 잔고. 합류 시점 지수 비율로 시드를 조정해 산정한다.
_Avoid_: 보정 시드, 지수 환산 잔고, 후발 시드

**lastAckedTickSeq (확인한 틱)**:
User 가 부재 요약을 확인 처리한 마지막 Tick. 부재 판정의 기준이며 **마지막 접속 시각이 아니다**.
_Avoid_: lastSeenAt, 마지막 접속, 최근 활동 (연결 기반 신호는 자동 재연결과 백그라운드 탭에서 전부 깨진다)

**leaderboardBlackout (암전)**:
폐장 직전 리더보드를 가리는 구간. 본인 계좌는 계속 열람할 수 있다.
_Avoid_: 블라인드, 비공개 구간, 마스킹 (마스킹은 이 구간의 효과이지 구간의 이름이 아니다)

**Adjustment Factor (분할 조정 계수)**:
**주식 수만 바뀌어** 끊긴 가격을 잇기 위해 원종가에 곱하는 값. 액면분할·역분할·주식배당·인적분할이 대상이고, 가치가 회사 밖으로 나가는 **현금배당·ETF 분배금은 대상이 아니다** — 그쪽은 배당락을 화면에 남긴다. **적재 전처리이며 런타임 개념이 아니다**.
_Avoid_: 수정 계수, 보정치, 분할 이벤트

**Daily Report (복기)**:
한 일차가 끝난 뒤 그날의 거래를 되짚어 보여 주는 기록. 시즌 중에는 지난 일차 것도 계속 열람할 수 있다.
_Avoid_: 리뷰, 회고, 결산
