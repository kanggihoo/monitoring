# 환경변수 관리 규칙

> 설정값 배치 판단 기준. 실행 절차는 [`../usage.md`](../usage.md) 참조.

## 1. 설정값 위치 기준

| 성격 | 위치 | 규칙 |
|---|---|---|
| **비밀값** (Secret, 토큰, 암호화 키, 비밀번호) | `.env` | 커밋 금지 |
| **환경별 가변값** (포트, origin, callback URL) | `.env` | 로컬/배포 분리 |
| **환경 무관 기본값** (로그 레벨, timeout 등) | `application.yml` | 직접 정의 |

> **판단 기준**: 비밀이거나 환경마다 다르면 `.env`, 아니면 `application.yml`.

---

## 2. 파일별 역할

- **`.env`**: 실제 설정값 (커밋 금지).
- **`.env.example`**: 키 목록 + **의미 주석** (값은 비우거나 로컬 예시만 작성, Git 커밋 대상).
- **`application.yml`**: `.env` 값 참조(`${...}`) 및 기본값 정의 (변수 설명 주석은 `.env.example`에 위임).

---

## 3. 환경변수 추가 절차

1. `.env.example`에 키 추가 및 **의미 주석 작성** (암호화 키 등은 생성 명령 포함).
2. `application.yml` 참조 변수명과 일치.
3. 컨테이너 전달 필요 시 `compose.yml` 변수명도 일치.

---

## 4. 보안 주의사항

- 토큰, Secret, 암호화 키는 환경변수/Secret 저장소로만 주입 (코드·문서·로그 노출 금지).
- `.env`, `.pem`, 민감정보는 Git 저장소 및 애플리케이션 로그에 남기지 않는다.
