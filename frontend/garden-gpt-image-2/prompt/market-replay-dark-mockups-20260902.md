# Market Replay — dark-mode mockup prompts

All seven desktop mockups preserve the earlier information architecture in the project dark system: frame #0C0E11; shell #15181C; cards #1D2126; sunken controls #262B31; borders #2E343B; main text #F2F4F6; muted text #939BA5; 12px cards. Prices only use rising #FF5C68 and falling #5B9BFF. The interface is data-dense, calm, Korean, and uses line charts only — never candlesticks, gradients, neon, glassmorphism, or arbitrary colorful accents.

Screens: overview dashboard with movers/ranking/chat/dual wallet; NVDA detail with chart and market/limit order panel; My Page with avatar chooser, provider account and withdrawal danger zone; Operations Console with replay control, event queue and health monitoring; social login with Google and Kakao; neutral logout dialog over dashboard; a 21:9 landing hero with timeline and financial UI panels.
